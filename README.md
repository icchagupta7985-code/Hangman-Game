🎮 Hangman Game – Python Mini Project

📌 Project Overview

Hangman Game is a simple text-based word guessing game developed using Python. The player has to guess a hidden word by entering one letter at a time before running out of attempts.

This project was developed as part of my CodeAlpha Python Internship to improve my programming and problem-solving skills.

✨ Features

* Random word selection from a predefined list.
* Maximum of 6 incorrect guesses allowed.
* Letter-by-letter word guessing.
* Tracks guessed letters.
* Displays the progress of the hidden word.
* Shows whether the player wins or loses.

🛠️ Technologies Used

* Python 3
* Random Module
* VS Code

⚙️ How to Run the Project

Step 1: Clone the repository.

git clone https://github.com/icchagupta7985-code/Hangman-Game.git

Step 2: Open the project folder.

cd Hangman-Game

Step 3: Run the Python file.

python3 hangman.py

🎯 How to Play

1. Run the Python program.
2. The computer randomly selects a secret word.
3. Guess one letter at a time.
4. Each incorrect guess reduces your remaining attempts.
5. Guess the complete word before using all 6 incorrect attempts to win!

📚 Learning Outcomes

Through this project, I practised:

* Python functions.
* Lists and strings.
* Conditional statements.
* Loops.
* Random module.
* User input handling.
* Basic problem-solving skills.
